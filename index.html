스프라이트 시트 규격 정규화

AI로 생성한, 프레임 크기가 제각각인 스프라이트 시트를 넣으면 각 캐릭터를 자동 검출해 동일한 셀 규격으로 재정렬합니다. 유니티 Grid By Cell Size로 바로 슬라이싱됩니다.

⊞

시트 이미지를 드래그하거나 클릭해서 업로드

PNG 권장 · 단색/투명 배경 · 프레임이 가로/세로 그리드로 나열된 시트

설정

비워두면 가장 큰 프레임 기준으로 자동 설정. 유니티에서 쓸 값 고정하려면 직접 입력 (예: 128 / 128).

자동 검출이 이상하면 원본 시트의 열/행 수를 직접 넣으세요. 예: 12열 4행이면 12 / 4.

발밑 중앙이 표준입니다.

비우면 검출된 프레임을 한 줄로 출력합니다. 예: 4 입력 시 결과물을 4열 그리드로 재배치합니다.

검출이 캐릭터를 자르면 낮추고, 배경 얼룩까지 잡으면 높이세요.

캐릭터가 하나로 뭉치면 낮추고, 한 캐릭터가 둘로 쪼개지면 높이세요.

검출된 배경색을 알파 0으로 지웁니다. 이미 투명한 PNG는 그대로 유지됩니다.

초록/파랑 배경으로 뽑았다면 크로마키를 선택하세요. 외곽 초록 얼룩(spill)까지 중화합니다.

배경색 직접 선택

배경으로 지울 색 범위. 배경이 남으면 높이고, 캐릭터가 지워지면 낮추세요.

외곽선에 밴 초록/파랑 색조를 눌러 중화합니다. 0이면 끔.

외곽선 옆에 낀 배경색 얼룩(AA 잔여물)을 파고들어 제거합니다. 0이면 원본 경계 유지, 높이면 더 깊게 깎습니다. 캐릭터가 깎이면 낮추세요.

AI 생성물의 뿌연 안티엘리어싱을 다운스케일+색 양자화+최근접 확대로 또렷한 픽셀로 정리합니다.

클수록 픽셀이 커지고 번짐이 줄지만 디테일도 뭉갭니다. 2~3 권장.

팔레트를 이 개수로 줄여 색 번짐을 없앱니다. 16~48이 픽셀 아트답습니다.
